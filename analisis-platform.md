# Bagian 2 — Analisis Komparatif Platform

## Tabel Analisis Komparatif Platform

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Bahasa utama** | JavaScript, TypeScript, HTML, CSS | C++, C#, Java, Swift, Python | Kotlin, Swift, Dart, JavaScript |
| **Arsitektur** | Client-Server (REST API/GraphQL, Microservices) | Standalone / Monolithic / Client-Server | Client-Server / Mobile-First Architecture |
| **Cara distribusi** | Web Browser via URL (Domain) | Installer (.exe, .dmg, .deb) / App Store | App Store (Google Play Store, Apple App Store) / APK |
| **Keunggulan** | Akses instan tanpa instalasi, *cross-platform*, pembaruan langsung dari server (*real-time update*) | Performa tinggi, akses penuh ke hardware/OS lokal, dapat berjalan offline secara optimal | Portabel, memanfaatkan fitur perangkat (GPS, Kamera, Sensor), notifikasi *push* |
| **Keterbatasan** | Keterbatasan akses hardware lokal, sangat bergantung pada koneksi internet | Membutuhkan instalasi dan pembaruan manual, keterbatasan kompatibilitas antar OS | Resource terbatas (baterai, RAM, layar kecil), proses *publishing* butuh review store |
| **Contoh aplikasi** | Google Docs, Trello, Figma Web | Visual Studio Code, Adobe Photoshop, Microsoft Word | WhatsApp, Instagram, Gojek |

# Refleksi Pembelajaran Platform Pemrograman

Platform yang paling menarik untuk saya pelajari adalah Visual Studio Code (VS Code), karena platform ini memiliki tampilan yang sederhana, fitur yang lengkap, dan mendukung berbagai bahasa pemrograman, seperti Python, C, dan C++. Selain itu, VS Code memudahkan saya dalam menulis, menjalankan, dan memperbaiki kode program. Saya juga dapat menggunakan berbagai ekstensi untuk membantu proses pembelajaran dan pengembangan program.

Tantangan terbesar yang saya hadapi saat melakukan setup environment adalah mengatur instalasi bahasa pemrograman, memastikan interpreter atau compiler terdeteksi dengan benar, serta mengatasi error ketika program dijalankan. Terkadang, program tidak dapat berjalan karena pengaturan path yang belum sesuai, modul yang belum terinstal, atau perbedaan versi Python yang tersedia di komputer. Hal tersebut membuat proses setup membutuhkan ketelitian dan kesabaran.

Rencana saya untuk mengatasi tantangan tersebut adalah mempelajari langkah-langkah instalasi dan konfigurasi environment secara bertahap. Saya akan memastikan bahasa pemrograman dan ekstensi yang diperlukan telah terpasang dengan benar, membaca pesan error dengan teliti, serta mencari solusi melalui dokumentasi resmi atau sumber pembelajaran yang terpercaya. Saya juga akan rutin berlatih membuat program sederhana agar semakin terbiasa menggunakan VS Code. Dengan cara tersebut, saya berharap dapat meningkatkan kemampuan pemrograman, menjadi lebih mandiri dalam menyelesaikan masalah, dan lebih siap mengerjakan proyek yang lebih kompleks.
